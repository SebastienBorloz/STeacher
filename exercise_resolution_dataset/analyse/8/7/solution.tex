\[\text{7. }\]
\[\text{Parabole : } y = a(x-1)^2 + 2\]
\[\text{Droite : } y = x + 3\]
\[\text{Intersection: } ax^2 - 2ax + a + 2 = x + 3\]
\[ \Rightarrow ax^2 - (2a+1)x + a - 1 = 0 \]
\[\text{Sol. double : } (2a+1)^2 - 4a(a-1) = 0\]
\[ \Rightarrow 8a + 1 = 0 \Rightarrow a = -\frac{1}{8} \]
\[\text{qui donne } -\frac{1}{8}x^2 - \frac{3}{4}x - \frac{9}{8} = 0 \Leftrightarrow x^2 + 6x + 9\]
\[ = (x+3)^2 = 0 \Rightarrow (x,y) = (-3,0) \]
